# Contributing

**No contributions. No pull requests, no issues, no support.** This repository is a read-only snapshot regenerated from a
private source repository (history is squashed), so there is nothing to merge back into. Issues and pull requests are not
monitored and may be closed without comment. All rights are reserved (see `LICENSE`); no permission to fork, run or
modify is granted by this file.

There is no `CODEOWNERS` file and no review process, because nothing is merged here.
